This is an allowance/claim mismatch, not evidence of a fixed-size buffer overflow. |

The external priorities are proposed remediation order, not adopted design changes.
In particular, a 512 total-instance policy, reliable roster channel and release
credential policy must be specified before implementation. Existing source and
runtime adoption remain distinct. The newer physics overlay and per-node
constraint index (ADRs 2169 and 2173) supersede older force-path descriptions.
